Demographic: ผู้หญิง 18-30 ปี ในไทย

Behavior: ชอบคอนเทนต์ before/after, อ่านรีวิว, เปรียบเทียบราคาและผลลัพธ์

Creative Signal: ภาษา, นางแบบ, ข้อความผลลัพธ์, โปรโมชัน, รีวิว, ราคา

จุดแข็ง

  • เปิดภาพช่วยผลลัพธ์ชัด ดูน่าสนใจ
  • สื่อ pain และ benefit ได้เร็ว
  • มีราคาและรีวิวช่วยเพิ่มความน่าเชื่อถือ

จุดอ่อน

  • ยังไม่มี handling objection มากพอ
  • CTA ยังทั่วไป ไม่เร่งการตัดสินใจ
  • Proof เชิงลึกยังน้อยถ้าต้องการ scale

สิ่งที่ควรแก้ทันที

  • เพิ่ม before / after หรือรีวิว 1-2 เคส
  • เพิ่มประโยคตอบข้อกังวล เช่น ผิวแพ้ง่ายใช้ได้ไหม
  • ปรับ CTA ให้ชัดขึ้น เช่น ทักเพื่อรับโปรวันนี้

Prompt สำหรับแก้ไข

ใช้ prompt นี้สำหรับให้ AI ช่วยแก้ภาพ โดยอิงจากรายการ “สิ่งที่ควรแก้ทันที” ด้านบน

รูปที่ Generate ใหม่

รอ Generate
ยังไม่มีรูปใหม่

กด Generate ทำรูปใหม่ เพื่อเตรียม prompt และแสดงผลลัพธ์ในช่องนี้เมื่อเชื่อม API สร้างภาพแล้ว

Hook ใหม่อย่างน้อย 5 ตัวเลือก

  1. สิวขึ้นทุกวัน? ลองตัวนี้ 7 วันเห็นผล
  2. ก่อนนอน 1 หยด ตื่นมาผิวใสขึ้น
  3. ผิวอ่อนล้า ฟื้นลุคให้ดูสดขึ้นเร็ว
  4. เซรั่มลดสิวที่ใช้แล้วอยากบอกต่อ
  5. ถ้าอยากผิวใสไว ลองเริ่มจากตัวนี้
